NULL//RUN PATCH NOTES

Version 0.0.10.1 - 2026-10-23
-----------------------------
- Regrouped the streak counter and timer bar, divider, and shield in the existing corner HUD container.
- Increased the desktop HUD scale to 1.2233 while preserving its top-right anchor, aligning its divider with the score divider.
- Kept the mobile HUD scale unchanged and updated release labels and project guidance for version 0.0.10.1.

Version 0.0.5 - 2026-10-23
--------------------------
- Enlarged the shield glyph, removed its square frame, and combined shield and streak status in a vertical HUD stack at the game field's upper-right corner.
- Rotated the streak timer into a bottom-up vertical bar beside its counter.
- Made shield drops progressively rarer during a run, tapering from 6% to a 1% minimum spawn chance.
- Updated the in-game hint, README, and release labels for version 0.0.5.

Version 0.0.4 - 2026-10-23
--------------------------
- Reduced shield-cell spawn probability from 14% to 6% per spawned object.
- Replaced the top-row shield counter with an icon in the game field's upper-right corner; its glow and check mark show when a shield is charged.
- Added a streak timer bar that drains across the 3.5-second shard combo window.
- Updated README instructions and release labels for version 0.0.4.

Version 0.0.3 - 2026-10-23
--------------------------
- Added collectible cyan shield cells. One shield absorbs a thorn collision and grants a brief invulnerability window; collecting another shield while charged awards 100 points.
- Added shard streaks. Consecutive shard pickups within 3.5 seconds build a combo, with increasing bonus points every third shard.
- Added shield and streak counters to the run HUD, plus a player shield ring and an on-screen combo callout.
- Updated the opening instructions, README, and release labels for version 0.0.3.

Version 0.0.2 - 2026-10-23
--------------------------
- Bumped the project release version from 0.0.1 to 0.0.2 in package metadata and the visible page labels.
- Added this patch-notes file to establish a versioned record of project changes.
- Updated the project README and contributor guidance to require a patch-note entry for every future project change.
- No gameplay behavior, controls, or scoring rules changed in this release.

Version 0.0.1 - Initial release
-------------------------------
- Created NULL//RUN as a dependency-free, three-lane browser arcade game, playable directly from index.html.
- Added a canvas-rendered animated game field, signal shards to collect, thorn pods to avoid, increasing difficulty, score tracking, and a locally saved personal best.
- Added keyboard and touch lane controls, pause/resume, restart, and responsive desktop/mobile presentation.
- Added version metadata, basic project documentation, and a JavaScript syntax-check command.
